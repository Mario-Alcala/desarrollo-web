# Dudas técnicas y consultas a IA

Integrante: Kevin Miguel García Montané — Integrante 2 | Herramienta: Codex

| Duda | Respuesta aplicada y aprendizaje |
|---|---|
| ¿Por qué push se rechaza con non-fast-forward? | El remoto tiene commits que la rama local aún no integró; se revisa y trae la referencia correcta antes del siguiente push. |
| ¿Por qué una rama no tiene upstream? | La rama local no tiene una rama remota asociada; se indica origen/rama o se configura seguimiento. |
| ¿Por qué git branch no muestra a Ángel? | Muestra ramas locales; git branch -a también muestra referencias remotas. |
| ¿Merge o rebase para integrar ramas compartidas? | Merge deja visibles los commits y la unión sin reescribir la rama compartida. |
| ¿Cómo resolver both modified en init.sql? | Revisar cada tabla, FK y columna contra la base acordada y los modelos Java; combinar cambios compatibles. |
| ¿Por qué catálogo responde 200 y no muestra productos? | Puede faltar una variedad relacionada a cultivo y cosecha con existencia; se revisa JOIN y conteos. |
| ¿Cómo evitar duplicar cosecha en Bodega? | Crear el lote desde el registro de cosecha; Bodega consulta ese mismo registro. |
| ¿Qué significa usuario tomado de sesión? | La actividad utiliza el ID autenticado y no permite capturar otro ID en un selector. |
| ¿Qué hace pull comparado con merge? | Pull descarga e integra la rama configurada; merge une una rama ya disponible con la actual. |
