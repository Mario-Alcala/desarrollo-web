# Dudas técnicas y consultas a IA

Integrante: Ángel de Jesús Nieto Hernández — Integrante 4 | Herramienta: ChatGPT

| Duda | Respuesta aplicada y aprendizaje |
|---|---|
| ¿Qué diferencia hay entre variedad, cultivo y cosecha? | Variedad tiene identidad comercial; cultivo representa lo sembrado; cosecha identifica el lote físico. |
| ¿Por qué maduración es por lote? | Una misma variedad puede tener lotes verdes y maduros al mismo tiempo. |
| ¿Por qué catálogo puede responder 200 y salir vacío? | El JOIN requiere variedades, cultivos y cosechas con disponibilidad. |
| ¿Necesito tabla separada para semilla, abono y fertilizante? | El esquema observado los unifica en insumos y usa una categoría. |
| ¿Por qué nombre y nombreUsuario no son intercambiables? | Deben coincidir los nombres del JSON, modelo Java y SQL. |
| ¿Dónde va la dirección solicitada al comprar? | En la entrega ligada a ese pedido para guardar el dato usado en esa operación. |
| ¿Cómo mostrar nombre del terreno en una parcela? | Consultar por idTerreno con JOIN, en vez de copiar el nombre como texto. |
| ¿Por qué usar DECIMAL y unidad para superficies? | Conserva fracciones y unidad consistente desde MySQL hasta la interfaz. |
