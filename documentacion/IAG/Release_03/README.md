# Evidencias de IA generativa — Reporte 3

Este directorio reúne los tres formatos del uso de IA para el reporte 3. El número 3 corresponde al reporte que anteriormente estaba nombrado como 04.

- [`r-ia-doc-03.md`](r-ia-doc-03.md): consultas para entender, depurar o documentar; no generación de código.
- [`declaracion-ia-03.md`](declaracion-ia-03.md): declaraciones por integrante. Los borradores identifican qué datos están documentados y cuáles requieren validación personal.
- `Integrante_01` a `Integrante_04`: un solo `r-ia-dev-s03.md` por integrante, con los usos de código de este periodo. Los directorios `Uso_##` guardan prompts, respuestas, reflexiones y evidencias de cada sesión.

El reporte general de actividades es [`../../reportes/r-act-03.md`](../../reportes/r-act-03.md). Las consultas de código anteriores a este periodo no se vuelven a atribuir al reporte 3.
