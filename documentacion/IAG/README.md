# Documentación de IA generativa

La documentación se organiza por release. Para el reporte 3, consulta [`Release_03/README.md`](Release_03/README.md). Ahí se conserva un único `r-ia-dev-s03.md` por integrante que tenga uso de IA documentado; cada carpeta `Uso_##` guarda la evidencia de una sesión.

Los otros formatos del mismo reporte son [`../reportes/r-act-03.md`](../reportes/r-act-03.md), con las actividades del equipo, y [`Release_03/r-ia-doc-03.md`](Release_03/r-ia-doc-03.md), con las consultas explicativas o de documentación.

No se duplican todas las clases del proyecto en cada sesión. Se guardan los archivos pertinentes, el diff entre hashes, el `numstat`, el prompt, la respuesta y la reflexión cuando hay evidencia. Los prompts reconstruidos desde un resumen se identifican como resumen, no como transcripción literal. Las declaraciones personales que requieren confirmación no se presentan como firmadas.

Los materiales de otros reportes se mantienen en sus carpetas o nombres originales; no deben mezclarse con `Release_03`.
